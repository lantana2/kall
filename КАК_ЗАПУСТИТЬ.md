# 🍎 Калории по фото

MVP-приложение на React Native (Expo). Фоткаешь еду → ИИ оценивает калории и БЖУ.

## Вариант А — поставить готовый APK (быстро, для теста)

На рабочем столе лежит файл **`Калории-по-фото.apk`**.

1. Перекинь его на Android-телефон (через кабель, Telegram «Избранное», Google Drive и т.п.).
2. На телефоне открой файл → разреши «установку из неизвестных источников» → установи.
3. Запусти приложение. При первом запуске откроется окно с полем для **API-ключа**.
4. Получи БЕСПЛАТНЫЙ ключ:
   - Зайди на https://openrouter.ai → зарегься (платить НЕ нужно).
   - https://openrouter.ai/keys → создай ключ.
   - Скопируй ключ (начинается на `sk-or-v1-...`).
5. Вставь ключ в приложении → «Сохранить ключ». Ключ сохранится на телефоне (вводить заново не нужно).
6. Жми «📷 Сфоткать», наведи на еду → через пару секунд увидишь калории.

> Приложение использует бесплатную vision-модель (`google/gemini-2.0-flash-exp:free`).
> Лимит — около 50 запросов в день, баланс пополнять не надо. Если выскочит
> «модель занята» — подожди минуту или поменяй модель в `config.js` (там есть список).

Поменять ключ можно в любой момент — кнопка ⚙ справа сверху.

> APK подписан отладочным ключом — для личного теста ок. Для публикации в Google Play
> нужна сборка с релизным ключом (отдельный шаг).

## Вариант Б — запуск через Expo Go (для разработки)

1. Поставь на телефон «Expo Go» (Play Market / App Store).
2. В папке проекта: `npx expo start`
3. Отсканируй QR-код (Android — в Expo Go, iPhone — камерой).

## Пересобрать APK заново (после изменений в коде)

```
cd android
.\gradlew.bat assembleRelease
```
Готовый файл: `android\app\build\outputs\apk\release\app-release.apk`

## Что это и ограничения

- Дневник хранится только в памяти (пропадает при перезапуске приложения).
- Оценка калорий **примерная** — ИИ угадывает вес порции по фото.
- Ключ хранится на телефоне (AsyncStorage), не в облаке.

## Файлы проекта

- `App.js` — экран и логика интерфейса.
- `lib/analyzeFood.js` — отправка фото в ИИ и разбор ответа.
- `config.js` — эндпоинт и модель ИИ (ключ теперь вводится в приложении).
- `android/` — нативный проект для сборки APK.
